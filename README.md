This folder contains two example cases to test the MERLIN multi stage despeckler. 

The two cases are from the Boston Harbor and Duck, NC.

Each folder contains an image of the SLC +y amplitude for the region that is included in the pickle file (not included here), 
the pixel cloud Water surface elevation with satellite map, and the python notebook to generate these files.

The pickle contains slc_plus_y and slc_minus_y and metadata
